# 健身小助手（网页）

回答几个问题，现场算出每周训练安排和 7 天饮食示例。所有计算都在手机浏览器里完成，不上传数据。

## 动作资料来源与授权

动作的名称、锻炼部位、器材和「怎么做」要点，来自开源项目 [wger](https://wger.de)（https://github.com/wger-project/wger）的动作数据库。

- 我们从中挑选了部分动作，由本页把英文说明改写成中文要点，并逐条标注 wger 动作编号和作者（见网页里每个动作的「怎么做」）。
- wger 的动作数据按 Creative Commons 授权：多数为 CC-BY-SA 4.0，部分为 CC-BY-SA 3.0 或 CC0，授权类型已在每条动作后标明。
- 因此本页中由 wger 数据改写而来的内容，同样按 **CC-BY-SA 4.0** 提供：使用时需要署名，改写后的内容也要用相同授权公开。
- 「膝盖 / 腰背 / 肩颈」的动作分类是本页按动作类型自行整理的，不是 wger 提供的，也不是医学判断。

## 示范图与视频

- `img/` 里的动作示范图来自 wger（wger.de），授权同上（CC-BY-SA 3.0/4.0），作者在页面每个动作的说明里标注。部分图上的文字是外文（例如西班牙文），是 wger 原图。
- 每个动作有「找教学视频」入口，指向 B 站搜索结果，视频内容不由本项目提供或审核。
- 想换成指定的示范视频：在 `index.html` 里的 `VIDEOS` 填上「动作中文名 → 视频链接」，该动作就会显示「看示范视频」。

## 食物营养数据来源

食物库和 7 天菜单里的热量、蛋白质、碳水、脂肪，来自美国农业部 [FoodData Central](https://fdc.nal.usda.gov/)（SR Legacy 数据集），为美国政府公开数据（公有领域）。每种食物在页面代码里附有 FDC 编号。中文名称、做法建议和份量换算由本页整理。菜单里的克数是按用户目标反推的估算。
